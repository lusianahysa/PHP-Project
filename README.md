# Parking Management System

A web application for managing parking spots and reservations, built as a semester project for the PHP course by a team of four.

## Features

- User registration and login
- Parking reservations
- Admin panel with a dashboard for statistics and financials

## Tech stack

- **Backend:** PHP
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript
- **Tools:** Git, GitHub, WAMP

## Run locally

1. Install WAMP and PostgreSQL.
2. Clone the repository into your WAMP web folder.
3. Create a PostgreSQL database and import the SQL files from the `database/` folder.
4. Set your database connection details in the project's configuration.
5. Open the project in your browser through `localhost`.
